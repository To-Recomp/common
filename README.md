# common

to-recomp/common

Shared C++17 library used by every game recomp: disc and archive reading, dump verification (Redump and file-level hashes), `dumps.toml` handling, instance configuration, and the SDL3 window, input and audio layer. Rendering stays in each platform backend.

Status: M0, repository skeleton only. First milestone is multi-disc GameCube (GCM) reading and hash verification.
